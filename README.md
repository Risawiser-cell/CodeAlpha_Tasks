# Java Projects

Beginner Java projects built during my Java development internship.

## 1. Java Chatbot (ChatbotApp.java)
FAQ chatbot with a Swing GUI. It cleans the text (lowercase, punctuation and stop-word removal), matches questions by word similarity, and learns new answers with the Train button.

## 2. Hotel Reservation System (HotelReservationSystem.java)
Console app to search rooms, book, cancel and view reservations. It prevents double bookings, simulates payment, and saves bookings to a CSV file.

## 3. Student Grade Tracker (StudentGradeTracker.java)
Console app to add students and grades, and view student and summary reports (average, highest, lowest).

## How to run
```
javac FileName.java
java FileName
```
Replace FileName with the project's file name, for example ChatbotApp.

## Concepts used
Java OOP, collections, file handling, exception handling, Swing GUI
